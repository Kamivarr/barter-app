SLAJD 4: Działające MVP i Architektura Techniczna
--------------------------------------------------------------------------------
Układ: 2 kolumny (Architektura & Stack Technologiczny ➔ Twarde Metryki Kodu z Repozytorium).

1. Kolumna 1: Nowoczesna Architektura Hybrydowa Next.js 16
   - Frontend: React 19, Tailwind CSS v4, Lucide Icons, industrialny Dark Mode (#0c0a09).
   - Logika Serwera: Next.js 16 App Router (RSC), 13 modułowych Server Actions z walidacją Zod.
   - Bezpieczeństwo i Sesja: Bezstanowe tokeny JWT w ciasteczkach HttpOnly (`jose`), Middleware na trasach prywatnych (`/dashboard`, `/items/new`, `/items/:id/edit`).
   - Baza i ORM: Prisma ORM 5.22, baza SQLite z wersjonowanymi migracjami.
   - Konteneryzacja: Czysty Docker Compose (`Dockerfile.dev` z Node 22 Alpine, izolacja wolumenów `node_modules` i cache Turbopack, trwały wolumen bazy).

2. Kolumna 2: Twarde Metryki Inżynierskie (Stan Repozytorium na Żywo)
   - 5 Modeli Relacyjnych Prisma: `User`, `Category`, `Item`, `RentalRequest`, `Review` (relacje 1:n oraz 1:1 dla recenzji).
   - 2 Ścisłe Enumy Domenowe TypeScript: `ToolCondition` (4 stany), `RentalStatus` (5 stanów maszyny wypożyczeń).
   - 8 Pełnych Kategorii Sprzętu: Od elektronarzędzi po transport i magazyn.
   - 111 Realistycznych Przedmiotów w Seederze: Z autentycznymi, zweryfikowanymi fotografiami Unsplash (100% kodów 200 OK) przypisanymi do dzielnic Rzeszowa.
   - 13 Modułowych Server Actions: Obsługa autoryzacji, publikacji ofert, kalendarza rezerwacji, PIN-u i recenzji.
   - 18 Komponentów UI: Czysta architektura Atomic Design w `components/` (ui, layout, items, rentals, dashboard).
   - 7 Dedykowanych Ekranów / Tras w `app/`: Katalog główny, szczegóły oferty, edycja, dodawanie, dashboard dwurolowy, logowanie, rejestracja.
   - Weryfikacja jakości: `npx prisma validate` = 0 błędów, `npx tsc --noEmit` = 0 błędów (100% Strict Type-Safety).
